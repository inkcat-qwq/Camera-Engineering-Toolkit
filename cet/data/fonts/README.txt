Noto Sans SC Regular (static weight-400 instance of the variable TrueType font)
Source: https://github.com/google/fonts/tree/main/ofl/notosanssc
Downloaded 2026-10-06 from:
https://raw.githubusercontent.com/google/fonts/main/ofl/notosanssc/NotoSansSC%5Bwght%5D.ttf

Distributed under the SIL Open Font License 1.1; see OFL.txt.
Instanced with fontTools.varLib.instancer at wght=400. The source defaults to
weight 100, which renders too faintly in Matplotlib. No glyphs were removed.
Bundled to render Chinese chart labels and user-entered component names on
Windows, macOS and Linux without a system font or a runtime network request.
